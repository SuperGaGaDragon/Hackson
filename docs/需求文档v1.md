Hardware + Software 

Basic overview: 
- Live Multi-Agent World + Physical AI Companion

- 硬件 + web page， ai协作团队。用户在web page自定义性格/目的，追踪项目等。ai协作项目追踪。

- 一个硬件 + Web UI 的多 AI （两个ai）桌面生态系统。用户可以创建不同性格的 AI 个体，观察它们的对话、生活、任务进度和关系变化，并在需要时让它们协作完成目标。（UI 项目进度监督层）

- agents 自成长 -> 在平时的idle/相互聊天中有性格变化成长。

- 工具类可以让agents调动codex cli


三种模式：

| 模式             | 作用                    | 例子                                          |
| -------------- | --------------------- | ------------------------------------------- |
| Idle Life Mode | AI 平时自己生活、闲聊、写日记、互相互动 | 两个 AI 在讨论今天做什么，一个 AI 在“看书”，一个 AI 在发呆        |
| Companion Mode | 用户和某个 AI 闲聊、陪伴、提问     | 桌宠猫陪你说话，性格可以是温柔/毒舌/PM/老师                    |
| Work Mode      | 多 AI 协作推进一个目标         | Planner 拆任务，Worker 写内容，Reviewer 质检，硬件显示进度状态 |
